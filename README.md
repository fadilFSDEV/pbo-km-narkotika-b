# KMS Putusan Pengadilan Narkotika

## Deskripsi Proyek
Proyek ini adalah Knowledge Management System (KMS) untuk mengelola putusan pengadilan pidana narkotika di Indonesia. Dibangun menggunakan bahasa Java (JDK 11+) dengan menerapkan arsitektur MVC (Model-View-Controller) dan prinsip-prinsip Pemrograman Berorientasi Objek (OOP) seperti enkapsulasi, polimorfisme, dan pewarisan.

## Cara Kompilasi dan Menjalankan (via Command Line)
1. Buka terminal atau command prompt
2. Pindah ke direktori sumber proyek:
   ```bash
   cd src
   ```
3. Kompilasi semua file Java:
   ```bash
   javac model/*.java controller/*.java view/*.java util/*.java app/*.java
   ```
4. Jalankan aplikasi:
   ```bash
   java app.Main
   ```
   ### Cara 2: Melalui IntelliJ IDEA (Lokal)


1.  *Clone Repository ke Komputer Anda*
    Buka terminal dan jalankan perintah berikut:
    bash
    git clone https://github.com/fadilFSDEV/pbo-km-narkotika-b.git


2.  *Buka Proyek di IntelliJ IDEA*
   - Buka IntelliJ IDEA.
   - Pilih *File > Open...*
   - Arahkan dan pilih folder pbo-km-narkotika-b yang baru saja Anda clone, lalu klik *OK*.
   - IntelliJ IDEA akan secara otomatis mendeteksi struktur proyek.

3.  *Jalankan Aplikasi*
   - Di panel Project di sebelah kiri, navigasi ke src > app > Main.java.
   - Klik kanan pada file Main.java.
   - Pilih *Run 'Main.main()'*.
   - Aplikasi akan dikompilasi dan dijalankan, dengan output yang muncul di konsol Run di bagian bawah IDE.
